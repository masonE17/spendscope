# SpendScope
- Zoom in on your spending.
- SpendScope is a full-stack expense tracker built with React and Vite. Add, categorize, and manage your expenses, then visualize your spending with interactive charts — all backed by Supabase.
  
## Features
- **Auth** — sign up or log in with secure authentication and row-level security
- **Add expenses** — log expenses with an amount, category, and date
- **Filtering** — narrow down expenses by category, date range, or amount
- **Summary statistics** — see totals and breakdowns of your spending at a glance
- **Visualizations** — interactive Recharts pie and bar charts showing spending by category
  
## Tech Stack
- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Recharts](https://recharts.org/) — data visualization
- [Supabase](https://supabase.com/) — auth, database (Postgres), and row-level security
- [Tailwind CSS](https://tailwindcss.com/) — styling
